# Internet XP v1.0.12

Navegador Android com **GeckoView 158** e interface XP adaptada para telefone.

## Novidades da v1.0.12
- Barra de endereço reduzida em altura e mais larga, aproveitando melhor o espaço horizontal.
- Novo botão de atualizar em estilo mais próximo ao Internet Explorer clássico.
- Seta de histórico dentro da barra de endereço, abrindo a lista de sites já acessados.
- Sugestões de histórico e favoritos enquanto o usuário digita.
- Módulo interno de downloads na parte de baixo, acima da barra principal, sem abrir diretamente a tela externa do sistema.
- Barra inferior principal reduzida em altura para ocupar menos espaço vertical.
